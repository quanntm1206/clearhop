# Security policy

## Supported versions

Security fixes target the latest tagged release and the default branch.

## Reporting

Use [GitHub private vulnerability reporting](https://github.com/quanntm1206/clearhop/security/advisories/new). Do not open a public issue. Include affected version, impact, and minimal reproduction steps. Remove personal audio, credentials, and model assets from reports.

## Privacy boundary

ClearHop processes WAV files locally. It has no telemetry or audio-upload path. Release assets are downloaded only by the installer and activated only after SHA-256 verification.
